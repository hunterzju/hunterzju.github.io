工欲善其事，必先利其器，好用的编辑器对于程序员来说至关重要。VIM是一款入门门槛略高，但是熟练以后让人爱不释手的编辑器。而且在Linux开发环境下，vim编辑器是极其容易获取的。此外，熟练使用VIM会给人很专业的感觉（装X神器）。

背景

然而，用好VIM并不是一件容易的事。好用的VIM离不开各种插件以及配置。这些插件安装起来有时候并不那么友好，比如在不同Linux发行版Centos和Ubuntu中搭建，还是要踩点坑的。虽然有现成的vimrc文件，但是每次迁移开发环境，还是要安装不少插件的依赖应用，并不是那么友好。因此就想将vim开发环境打包到docker容器中，免去安装依赖的烦恼。

实现

基于开源项目，略微修改了一下，将vim打包到了容器镜像中：docker-vim.

使用说明：

  1. 拉取github仓库：https://github.com/hunterzju/docker-vim.git
  2. 构建docker镜像：cd docker-vim && make build-vim && make install
  3. 在对应项目中使用：cd $path_to_project && dvim

每次执行dvim会拉起一个docker容器并进入shell，当前目录会被挂载在docker容器中的/home/workspace目录

容器中包含了vim的简单配置：

vim_runtime

使用vim_runtime来管理配置，该项目也是开源项目，里面自带了一些常用插件。详情可以参考对应项目主页。

在vim_runtime环境中，定制化的vim配置放在/home/user/.vim_runtime/my_configs.vim文件中。自己习惯的键位映射，插件的配置都放在这里。

vim_plugs

vim-plug是一个非常方便的vim插件管理工具。需要添加插件时，只要在my_configs.vim文件中加入对应的插件路径，然后在vim中执行PlugInstall就可以了。比如如下插件：

call plug#begin("~/.vim_runtime/my_plugins/")
 Plug 'junegunn/fzf', { 'do': { -> fzf#install() } }
 Plug 'Yggdroot/LeaderF', { 'do': ':LeaderfInstallCExtension' }
call plug#end()
