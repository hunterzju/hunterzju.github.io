python中字节码实现

Created At：2024-08-18 20:12 Updated At：2024-08-18 20:43

在学习pytorch中dynamo优化时，相关日志中有很多字节码的处理，怎么看懂python字节码是理解dynamo的前提之一。python官方文档中介绍可以通过dis模块获取python源码对应的字节码：https://docs.python.org/3/library/dis.html#bytecodes

但是还是不清楚字节码的布局和结构，需要到python源码中寻找答案。

字节码结构

python中字节码定义在Python-3.12.4/Include/opcode.h中，其中列举了所有字节码的opcode，但是对应的opcode是什么含义，其后的参数又代表了什么？还是无法解惑，于是就想要看看字节码是如何被解析的？查看源码Python-3.12.4/Python/ceval_macros.h中的dispatch方法

/* Do interpreter dispatch accounting for tracing and instrumentation */
#define DISPATCH() \
    { \
        NEXTOPARG(); \
        PRE_DISPATCH_GOTO(); \
        DISPATCH_GOTO(); \
    }

展开上述宏定义：

#define NEXTOPARG()  do { \
        _Py_CODEUNIT word = *next_instr; \
        opcode = word.op.code; \
        oparg = word.op.arg; \
    } while (0)
    
typedef union {
    uint16_t cache;
    struct {
        uint8_t code;
        uint8_t arg;
    } op;
} _Py_CODEUNIT;

#  define DISPATCH_GOTO() goto dispatch_opcode

可以看出字节码结构由op.code和op.arg两部分构成，每部分8bit。

字节码执行

知道了字节码结构，python执行时如何处理对应的字节码呢？运行时的处理逻辑在Python/ceval.c的_PyEval_EvalFrameDefault函数中，根据其中的dispatch逻辑，字节码的具体处理逻辑在Python-3.12.4/Python/generated_cases.c.h中，以LOAD_FAST字节码为例，其实现如下：

        TARGET(LOAD_FAST) {
            PyObject *value;
            #line 192 "Python/bytecodes.c"
            value = GETLOCAL(oparg);
            assert(value != NULL);
            Py_INCREF(value);
            #line 90 "Python/generated_cases.c.h"
            STACK_GROW(1);
            stack_pointer[-1] = value;
            DISPATCH();
        }

其具体逻辑是根据oparg从localvar中取具体的值，同时增加对应值的引用计数；然后扩充栈空间，并将取出的值放到栈顶，之后再出发dispatch逻辑取下一条字节码执行。
