torch.optimize装饰器

示例程序：

from typing import List
import torch
from torch import _dynamo as torchdynamo
def my_compiler(gm: torch.fx.GraphModule, example_inputs: List[torch.Tensor]):
    print("my_compiler() called with FX graph:")
    gm.graph.print_tabular()
    return gm.forward  # return a python callable

@torchdynamo.optimize(my_compiler)
def toy_example(a, b):
    x = a / (torch.abs(a) + 1)
    if b.sum() < 0:
        b = b * -1
    return x * b
for _ in range(100):
    toy_example(torch.randn(10), torch.randn(10))

装饰器torchdynamo.optimize是在_TorchDynamoContext中实现的，在__enter__函数中通过set_eval_frame()将python解释器中eval_frame行为替换成了convert_frame._convert_frame中定制的行为。

此处set_eval_frame()实际调用了torch/csrc/dynamo/eval_frame.c中的对应函数，利用PEP523提案，修改了解释其方法：

static PyObject* set_eval_frame(PyObject* new_callback, PyThreadState* tstate) {
  // Change the eval frame callback and return the old one
  //  - None: disables TorchDynamo
  //  - False: run-only mode (reuse existing compiles)
  //  - Python callable(): enables TorchDynamo
  PyObject* old_callback = eval_frame_callback_get();

  // owned by caller
  Py_INCREF(old_callback);

  if (old_callback != Py_None && new_callback == Py_None) {
    decrement_working_threads(tstate);
  } else if (old_callback == Py_None && new_callback != Py_None) {
    increment_working_threads(tstate);
  }

  Py_INCREF(new_callback);
  Py_DECREF(old_callback);

  // Set thread local callback. This will drive behavior of our shim, if/when it
  // is installed.
  eval_frame_callback_set(new_callback);

  return old_callback;
}

    def LOAD_FAST(self, inst):
        name = inst.argval

        if self.exec_recorder and name in self.f_locals:
            self.exec_recorder.add_local_var(name, self.f_locals[name])

        try:
            self.push(self.symbolic_locals[name].unwrap())
        except KeyError:
            if name.startswith("."):
                try:
                    # This happens in dict/list comprehensions
                    self.push(self.symbolic_locals[name.replace(".", "implicit")])
                except KeyError:
                    unimplemented("undefined LOAD_FAST (implicit)")
            else:
                unimplemented("undefined LOAD_FAST")

        # for continuation functions
        if name.startswith("___stack"):
            self.symbolic_locals.pop(name)

fx.Graph如何被构建

  • [ x ] VariableTracker是如何构建fx.Graph的？

在字节码模拟执行过程中，LOAD_FAST将对应变量Push到栈上，被Push的变量类型是VariableTracker；VariableTracker管理了guard相关信息。同样的LOAD_GLOBAL也会构建对应的VariableTracker：

    def LOAD_GLOBAL(self, inst):
        if self.output.global_scope is self.f_globals:
            super().LOAD_GLOBAL(inst)
        else:
            if sys.version_info >= (3, 11):
                if inst.arg % 2:
                    self.PUSH_NULL(inst)

            name = inst.argval
            if inst.argval == "AssertionError":
                unimplemented("assert with non-string message")

            _, fglobals_vt, global_source = self.get_globals_source_and_value(name)
            if self.output.side_effects.has_pending_mutation_of_attr(fglobals_vt, name):
                self.push(self.output.side_effects.load_attr(fglobals_vt, name))
            else:
                try:
                    value = self.f_globals[name]
                except KeyError:
                    return self.load_builtin(inst)

                self.push(VariableBuilder(self, global_source)(value))

在VariableBuilder被调用时，会进入包装过程，将Python value包装成对应的Tracker：

    def __call__(self, value):
        if value in self.tx.output.side_effects:
            side_effect_result = self.tx.output.side_effects[value]
            dup_guard = make_dupe_guard(self.source, side_effect_result.source)
            if dup_guard:
                self.install_guards(dup_guard)
            return side_effect_result

        cached_vt = self.tx.output.variable_tracker_cache.lookup(value, self.source)
        if cached_vt:
            return cached_vt

        vt = self._wrap(value)
        vt.source = self.source
        if self._can_lift_attrs_to_inputs(vt):
            vt = self.tx.output.side_effects.track_object_existing(value, vt)

        self.tx.output.variable_tracker_cache.add(value, self.source, vt)
        return vt

具体包装过程在self._wrap中，会完成install_guard和fx.graph构建行为。

具体而言，torch.fx.Graph的构建是通过Tracer来实现的，而Tracer保存在Class Outgraph中。模拟执行过程中，所有变量都被包装到了VariableTracker中；VariableTracker通过VariableBuilder构建，在__call__方法中会将python value包装为VariableTracker; 而OutputGraph是torch.fx.Tracer的一个子类，pytorch中torch.fx.Graph中间表示通过Tracer构建；在VariableBuilder过程中，会通过tx.Tracer返回对应的Proxy，从而构建fx.Graph，同时也会为对应的节点install_guard。
