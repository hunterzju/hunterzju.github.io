# Qwen3.5-35B-A3B-GPTQ-Int4 模型结构分析

基于 `config.json` 和 `model.safetensors.index.json` 源码分析。

---

## 一、整体架构全景

```
Qwen3_5MoeForConditionalGeneration
├── Vision Encoder (27层 ViT)
│   ├── patch_embed (Conv2d, patch_size=16, temporal_patch_size=2)
│   ├── pos_embed (2304 位置编码)
│   ├── 27× VisionBlock
│   │   ├── norm1 (LayerNorm, 1152)
│   │   ├── attn (qkv + proj, 16 heads)
│   │   ├── norm2 (LayerNorm, 1152)
│   │   └── mlp (linear_fc1 + linear_fc2, intermediate=4304)
│   └── merger (norm + linear_fc1 + linear_fc2, 1152→2048)
├── Language Model (40层 Decoder-only)
│   ├── embed_tokens (vocab_size=248320, hidden_size=2048)
│   ├── 40× Transformer Layer
│   │   ├── input_layernorm (RMSNorm, eps=1e-6)
│   │   ├── Attention (两种之一):
│   │   │   ├── [30层] linear_attn → Mamba2 SSM
│   │   │   └── [10层] self_attn → Full Softmax Attention (GQA)
│   │   ├── post_attention_layernorm (RMSNorm, eps=1e-6)
│   │   └── mlp (MoE):
│   │       ├── gate (Router, 256→8 路由)
│   │       ├── shared_expert_gate (二分类门控)
│   │       ├── shared_expert (gate+up+down, intermediate=512, bf16)
│   │       └── 256× Expert (gate+up+down, intermediate=512, 4-bit GPTQ)
│   └── norm (final RMSNorm, eps=1e-6)
├── lm_head (Linear, 2048→248320, untied)
└── MTP (Multi-Token Prediction, 1层)
    ├── pre_fc_norm_embedding / pre_fc_norm_hidden
    ├── self_attn (q/k/v/o_proj + q/k_norm)
    ├── mlp (gate + shared_expert + 256 experts)
    ├── post_attention_layernorm
    └── norm
```

## 三、每层详细算子和矩阵映射

### 3.1 Linear Attention 层 (Mamba2 SSM)

**适用层: 0,1,2,4,5,6,8,9,10,12,13,14,16,17,18,20,21,22,24,25,26,28,29,30,32,33,34,36,37,38**

核心参数:

- `linear_num_key_heads`: 16, `linear_key_head_dim`: 128
- `linear_num_value_heads`: 32, `linear_value_head_dim`: 128
- `linear_conv_kernel_dim`: 4

|权重名称|Tensor Shape|参数量|算子|说明|
|---|---|---|---|---|
|`linear_attn.A_log`|`[16, 128]`|2,048|`exp(A_log)`|SSM 状态转移矩阵 A，对数参数化|
|`linear_attn.dt_bias`|`[4096]`|4,096|`softplus(dt_bias)`|时间步长 Δ 偏置|
|`linear_attn.conv1d.weight`|`[4096, 4]`|16,384|`DepthwiseConv1d`|深度可分离卷积，kernel_size=4|
|`linear_attn.in_proj_a.weight`|`[2048, 2048]`|4,194,304|`x @ W_a`|SSM 输入投影 A (B矩阵)|
|`linear_attn.in_proj_b.weight`|`[2048, 2048]`|4,194,304|`x @ W_b`|SSM 输入投影 B (C矩阵)|
|`linear_attn.in_proj_qkv.weight`|`[10240, 2048]`|20,971,520|`x @ W_qkv`|合并投影 Q(2048)+K(4096)+V(4096)|
|`linear_attn.in_proj_z.weight`|`[2048, 2048]`|4,194,304|`x @ W_z`|输出门控投影|
|`linear_attn.norm.weight`|`[4096]`|4,096|`RMSNorm`|输出 RMS 归一化|
|`linear_attn.out_proj.weight`|`[2048, 4096]`|8,388,608|`x @ W_o`|输出投影回 hidden_size|
|**Subtotal**||**~41.97M**|||

**Mamba2 核心计算流:**

```
x [B, L, 2048]
  │
  ├──→ in_proj_qkv: x @ W_qkv → [B, L, 10240] → split → Q[2048], K[4096], V[4096]
  ├──→ in_proj_z:   x @ W_z   → [B, L, 2048]
  ├──→ in_proj_a:   x @ W_a   → [B, L, 2048] (B matrix)
  └──→ in_proj_b:   x @ W_b   → [B, L, 2048] (C matrix)

V → conv1d → SiLU → SSM(A, B, C, Δ) → norm → V'
V' ⨂ SiLU(z) → out_proj: V_out @ W_o → [B, L, 2048]
```

**矩阵映射:**

```
in_proj_qkv:  [B, L, 2048] × [10240, 2048]ᵀ → [B, L, 10240]    # 大矩阵乘法
out_proj:     [B, L, 4096] × [2048, 4096]ᵀ  → [B, L, 2048]     # 大矩阵乘法
其余投影:     [B, L, 2048] × [2048, 2048]ᵀ  → [B, L, 2048]     # 中等矩阵乘法
```

### 3.2 Full Attention 层 (Softmax Attention + GQA)

**适用层: 3,7,11,15,19,23,27,31,35,39**

核心参数:

- `num_attention_heads`: 16, `head_dim`: 256
- `num_key_value_heads`: 2 (GQA, ratio 8:1)
- `attention_bias`: false

|权重名称|Tensor Shape|参数量|算子|说明|
|---|---|---|---|---|
|`self_attn.q_proj.weight`|`[4096, 2048]`|8,388,608|`x @ W_q`|Q投影: 2048→4096 (16头×256)|
|`self_attn.k_proj.weight`|`[512, 2048]`|1,048,576|`x @ W_k`|K投影: 2048→512 (2头×256)|
|`self_attn.v_proj.weight`|`[512, 2048]`|1,048,576|`x @ W_v`|V投影: 2048→512 (2头×256)|
|`self_attn.q_norm.weight`|`[256]`|256|`RMSNorm`|Q per-head 归一化|
|`self_attn.k_norm.weight`|`[256]`|256|`RMSNorm`|K per-head 归一化|
|`self_attn.o_proj.weight`|`[2048, 4096]`|8,388,608|`x @ W_o`|输出投影: 4096→2048|
|**Subtotal**||**~18.87M**|||

**RoPE (旋转位置编码):**

```json
{
  "rope_type": "default",
  "rope_theta": 10000000,
  "partial_rotary_factor": 0.25,
  "mrope_interleaved": true,
  "mrope_section": [11, 11, 10]
}
```

- `partial_rotary_factor: 0.25` → 每头 256 维中仅旋转前 64 维
- `mrope_section: [11, 11, 10]` → 3D 多模态 RoPE（文本 11 组, 图像 11 组, 视频 10 组, 每组 2 维）

**Full Attention 计算流:**

```
x [B, L, 2048]
  │
  ├── q = x @ W_q → reshape [B, L, 16, 256] → q_norm → RoPE(q)
  ├── k = x @ W_k → reshape [B, L, 2, 256]  → k_norm → RoPE(k)
  └── v = x @ W_v → reshape [B, L, 2, 256]

k' = repeat_kv(k, 8)  # GQA: 2 KV heads → 16 heads
v' = repeat_kv(v, 8)

attn = softmax(q @ k'ᵀ / √256)  # [B, L, 16, L]
o = attn @ v'                     # [B, L, 16, 256]
o = reshape(o, [B, L, 4096]) @ W_o → [B, L, 2048]
```

### 3.3 MoE FFN 层 (所有 40 层共享此结构)

**参数量 (每层):**

|权重名称|Tensor Shape|参数量|精度|说明|
|---|---|---|---|---|
|`mlp.gate.weight`|`[256, 2048]`|524,288|bf16|Router，选 top-8|
|`mlp.shared_expert_gate.weight`|`[1, 2048]`|2,048|bf16|共享专家门控标量|
|`mlp.shared_expert.gate_proj`|`[512, 2048]`|1,048,576|bf16|共享 expert gate|
|`mlp.shared_expert.up_proj`|`[512, 2048]`|1,048,576|bf16|共享 expert up|
|`mlp.shared_expert.down_proj`|`[2048, 512]`|1,048,576|bf16|共享 expert down|
|Per Expert (×256):|||||
|`experts.N.gate_proj`|`[512, 2048]`|1,048,576|**4-bit GPTQ**|Expert gate 投影|
|`experts.N.up_proj`|`[512, 2048]`|1,048,576|**4-bit GPTQ**|Expert up 投影|
|`experts.N.down_proj`|`[2048, 512]`|1,048,576|**4-bit GPTQ**|Expert down 投影|
|Subtotal (256 experts)||256 × 3,145,728 = **805,306,368**|4-bit||
|**Subtotal (shared)**||**~3.15M**|bf16||
|**每层 MoE 总计**||**~808.5M**|||
|**40 层 MoE 总计**||**~32.34B**|||

**MoE 路由计算流:**

```
x [B, L, 2048]

# Router
logits = x @ W_gate          # [B, L, 2048] × [256, 2048]ᵀ → [B, L, 256]
weights = softmax(topk(logits, k=8))  # 每个 token 选 8 个 expert

# Expert 计算 (每 token 仅激活 8/256)
for each selected expert i:
  hidden_i = SiLU(x @ W_gate_i) ⨂ (x @ W_up_i)  # [B, L, 512]
  out_i = hidden_i @ W_down_i                      # [B, L, 2048]

expert_out = Σ(weights_i × out_i)  # 加权求和

# 共享 Expert
shared_gate = sigmoid(x @ W_sg)                    # [B, L, 1]
shared_hidden = SiLU(x @ W_sg_gate) ⨂ (x @ W_su)  # [B, L, 512]
shared_out = shared_gate × (shared_hidden @ W_sd)  # [B, L, 2048]

output = expert_out + shared_out                    # [B, L, 2048]
```

## 五、GPTQ 4-bit 量化映射

### 5.1 量化配置

```json
{
  "bits": 4,
  "group_size": 128,
  "damp_percent": 0.01,
  "desc_act": false,
  "static_groups": false,
  "sym": true,
  "true_sequential": true,
  "quant_method": "gptq",
  "dynamic": {
    "lm_head": {},
    "model.language_model.embed_tokens": {},
    "-:.*attn.*": {},
    "-:.*shared_expert.*": {},
    "-:.*mtp.*": {},
    "-:.*visual.*": {}
  }
}
```

### 5.2 哪些层被量化 vs 不量化

|组件|量化状态|精度|原因|
|---|---|---|---|
|`lm_head.weight`|**不量化**|bf16|Dynamic 规则明确排除|
|`embed_tokens.weight`|**不量化**|bf16|Dynamic 规则明确排除|
|`*.linear_attn.*`|**不量化**|bf16|`.*attn.*` 正则匹配排除|
|`*.self_attn.*`|**不量化**|bf16|`.*attn.*` 正则匹配排除|
|`*.shared_expert.*`|**不量化**|bf16|`.*shared_expert.*` 排除|
|`*.mlp.gate` (Router)|**不量化**|bf16|未匹配量化规则|
|`*.mlp.experts.*`|**量化**|4-bit|MoE Expert 独占量化|
|`mtp.*`|**不量化**|bf16|明确排除|
|`model.visual.*`|**不量化**|fp32|明确排除|

**结论: 仅 MoE Expert 的 `gate_proj` / `up_proj` / `down_proj` 被 4-bit 量化，其余全部保留原始精度。**

### 5.3 量化存储格式

每个 4-bit 量化权重矩阵存储为 4 个数组:

```
qweight:  uint32[ ceil(rows/8) ][ cols ]  每 8 个 4-bit 值打包为 1 个 uint32
qzeros:   uint32[ ceil(rows/8) ][ groups ] 每组 (group_size=128) 1 个零点
scales:   fp16[ rows ][ groups ]           每组 1 个 fp16 缩放因子
g_idx:    int32[ cols ]                    每列所属 group 索引 (desc_act=false 时冗余)
```

解量化: `weight = (unpack(qweight) - zero) × scale`

形状示例 (gate_proj: [512, 2048], group_size=128):

- `qweight`: `ceil(512/8) × 2048 = 64 × 2048` 个 uint32
- `qzeros`: `64 × 16` 个 uint32 (2048/128=16 groups)
- `scales`: `512 × 16` 个 fp16
- `g_idx`: `2048` 个 int32

## 七、推理时张量形状与内存估算

### 7.1 单 token 推理 (prefill 1 token)

|阶段|输入 Shape|输出 Shape|关键 GEMM|
|---|---|---|---|
|Embedding|`[1, 2048]` (lookup)|`[1, 2048]`|无|
|Linear Attn in_proj_qkv|`[1, 2048]`|`[1, 10240]`|`2048×10240`|
|Linear Attn out_proj|`[1, 4096]`|`[1, 2048]`|`4096×2048`|
|Full Attn q_proj|`[1, 2048]`|`[1, 4096]`|`2048×4096`|
|Full Attn k/v_proj|`[1, 2048]`|`[1, 512]`|`2048×512`|
|MoE gate_proj (8 experts)|`[1, 2048]`|`[1, 512]` × 8|`2048×512` × 8|
|MoE down_proj (8 experts)|`[1, 512]`|`[1, 2048]` × 8|`512×2048` × 8|
|LM Head|`[1, 2048]`|`[1, 248320]`|`2048×248320` (最大 GEMM)|

### 7.2 KV Cache (full_attention 层, 10 层)

每层 KV cache: `2 × seq_len × num_kv_heads × head_dim × 2 bytes` = `2 × L × 2 × 256 × 2` = `2048L bytes`

|Seq Length|KV Cache 总大小 (10 层)|
|---|---|
|1,024|20 MB|
|32,768|640 MB|
|262,144|5 GB|

### 7.3 SSM State (linear_attention 层, 30 层)

每层 SSM state: `num_value_heads × value_head_dim × head_dim` = `32 × 128 × 128` = 524,288 (per token, 不随 seq_len 增长)

30 层总计: `30 × 524,288 × 2 bytes = ~31 MB` (固定，不随序列长度增长，这是线性注意力的核心优势)
