大模型给编程开发带来极大助力，很多人认为程序员在用技术革自己的命。但是笔者认为大模型能够将我们从低级的重复劳动中解放出来，花更多的精力去干更有价值，更有创造力的事情。
nvim这种轻量级的IDE更加轻便，重要的是可以在开发服务器上保留工作环境，不会像vscode一样，换一台机器登陆，得重新加载远程目录，因此笔者还是比较喜欢nvim/vim这类IDE。美中不足的是当前一些大模型并没有提供nvim的官方插件（说的就是通义灵码），于是乎就自己调用API开发一个吧。

## nvim插件结构
nvim支持lua编写的插件，一个基本lua插件配置如下
```text
nvim-lingma/
├── lua/
│   └── lingma/
│       ├── core.lua       # 核心功能：API 调用、请求处理
│       ├── ui.lua         # UI 显示：浮动窗口、提示
│       └── init.lua       # 插件入口，对外暴露 API 和命令
├── plugin/lingma.vim      # 自动加载命令和默认配置
├── README.md              # 说明文档
├── LICENSE                # 开源协议（可选）
└── .luarc.json            # Lua LSP 配置（可选）
```

开发过程中如果想查看nvim开发lua相关文档，可以在nvim中执行：`:help lua-guide`

nvim中提供的API参考：
https://neovim.io/doc/user/api.html

## 通义API调用

在[ali百炼大模型服务平台](https://bailian.console.aliyun.com/?spm=a2c4g.11186623.nav-v2-dropdown-menu-0.d_main_0_0_0.28cc363awnSXGt&tab=doc&scm=20140722.M_10863655._.V_1#/doc/?type=model&url=2850166)开通api服务，并配置api-key，申请配置完成后，将api-key导出到环境变量：
```bash
# 用您的百炼API Key代替YOUR_DASHSCOPE_API_KEY
echo "export DASHSCOPE_API_KEY='YOUR_DASHSCOPE_API_KEY'" >> ~/.bashrc
```

API调用demo如下：
```python
import os
from openai import OpenAI

try:
    client = OpenAI(
        # 若没有配置环境变量，请用阿里云百炼API Key将下行替换为：api_key="sk-xxx",
        api_key=os.getenv("DASHSCOPE_API_KEY"),
        base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    )

    completion = client.chat.completions.create(
        model="qwen-plus",  # 模型列表：https://help.aliyun.com/zh/model-studio/getting-started/models
        messages=[
            {'role': 'system', 'content': 'You are a helpful assistant.'},
            {'role': 'user', 'content': '你是谁？'}
            ]
    )
    print(completion.choices[0].message.content)
except Exception as e:
    print(f"错误信息：{e}")
    print("请参考文档：https://help.aliyun.com/zh/model-studio/developer-reference/error-code")
```

使用curl发起http请求的话：
```curl
curl -X POST https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation \
-H "Authorization: Bearer $DASHSCOPE_API_KEY" \
-H "Content-Type: application/json" \
-d '{
    "model": "qwen-plus",
    "input":{
        "messages":[      
            {
                "role": "system",
                "content": "You are a helpful assistant."
            },
            {
                "role": "user",
                "content": "你是谁？"
            }
        ]
    },
    "parameters": {
        "result_format":"message"
    }
}'
```

## 调试技巧

发布前，将本地编写的插件加载到nvim中调试：
```
-- ~/.config/nvim/lua/custom/plugins.lua

return {
  {
    -- 不要写字符串名称
    dir = "~/projects/nvim-lingma",  -- 使用 dir 而不是 path
    name = "nvim-lingma",            -- 可选：自定义显示名
    config = function()
      require("lingma").setup({
        api_key = "sk-your-api-key",
      })
    end,
  },
}
```
